# Secret Rotation Guide

## Immediate Actions (Within 24 hours)

### 1. Supabase Service Role Key
1. Go to: https://app.supabase.com/project/_/settings/api
2. Click "Roll new key" next to service_role key
3. Update in:
   - Render Dashboard → Environment Variables → SUPABASE_SERVICE_KEY
   - Password manager
4. Test backend health check

### 2. JWT_SECRET
1. Generate new secret: `openssl rand -hex 32`
2. Update in:
   - Render Dashboard → Environment Variables → JWT_SECRET
   - All deployment environments
3. Restart all services

### 3. Brevo SMTP Password
1. Go to: https://app.brevo.com/settings/keys/api
2. Generate new SMTP password
3. Update in:
   - Render Dashboard → Environment Variables → SMTP_PASS
4. Test email sending

### 4. Vercel OIDC Token
1. Go to: https://vercel.com/account/settings/tokens
2. Revoke existing token
3. Generate new token
4. Update in:
   - backend/admin/.env.local (add to .gitignore if not already)
   - Password manager
5. Change Vercel account password

### 5. Verify .gitignore
Ensure these are in .gitignore:
- *.env
- *.env.local
- *.env.production
- backend/.env
- backend/admin/.env.local
- front-end/.env.local

### 6. Clean Local Files
After rotation:
1. Move all .env files to password manager
2. Delete from disk: `rm backend/.env backend/admin/.env.local`
3. Verify with: `git ls-files | grep .env`
